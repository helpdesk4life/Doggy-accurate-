maps.thomasfeyens.be

Static map assets for Mikywalk, served by Caddy over HTTPS with a Let’s Encrypt certificate.

  • /benelux.pmtiles — Benelux vector tiles, PMTiles v3, zoom 0–15, ~2.85 GB. A browser cannot render this file; paste the URL into pmtiles.io to sanity-check the archive.
  • /fonts/…/0-255.pbf — glyph ranges for MapLibre. These responses deliberately carry no ETag or Last-Modified, because MapLibre Native mishandles a 304 on glyphs.
  • /sprites/v4/dark.png and dark.json — sprite sheets, same no-validator rule.

Range requests are supported (Accept-Ranges: bytes), which is what a PMTiles client needs. This host is consumed by the app, not by a browser tab; there is no map page here on purpose.
